# DoggyFeed

A lightweight meal-planning app for tracking food nutrition across multiple dogs.

## Run

Open `index.html` in a modern browser. No build step or dependencies are required.

## Features

- Keep individual dog profiles, weights, life stages, and activity estimates.
- Maintain a food library with energy, protein, fat, and fiber values per 100 g.
- Add foods and serving amounts to each dog's bowl to calculate nutrition totals.
- Save profiles, foods, and meal plans in the browser's local storage.

The starter foods are sample entries. Verify nutrition values against product labels or a trusted database. The energy reference is a rough estimate, not a feeding prescription or veterinary advice. Data stays in the current browser and is not synced to an account or server.
